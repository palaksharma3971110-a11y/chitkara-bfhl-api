
# Chitkara Qualifier 1 REST API
This project is a Node.js REST API developed for Chitkara University Qualifier 1.

# Tech Stack
- Node.js
- Express.js

# API Endpoints

# POST/bfhl
Processes input data and returns required response.

# GET/health
Returns API health status.

# Run Locally
```bash
npm install
node index.js
